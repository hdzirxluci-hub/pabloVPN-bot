# 🚀 PabloVPN-Bot

ربات حرفه‌ای فروش VPN تلگرام با پشتیبانی از پنل‌های Marzban، 3X-UI، Sanaei و Pasargad

## ✨ ویژگی‌ها
- 🎨 برندینگ کامل و قابل شخصی‌سازی
- 💳 سه روش پرداخت (کارت به کارت، ارز دیجیتال، درگاه ریالی)
- 👛 کیف پول
- 🎁 سیستم زیرمجموعه‌گیری
- 🏷️ کد تخفیف
- 💬 سیستم پشتیبانی (تیکت)
- 🔒 عضویت اجباری
- 💾 بکاپ/ریستور کامل
- 📊 آمار پیشرفته

## 🚀 نصب روی Railway
1. این ریپو رو Fork کن
2. در Railway → New Project → Deploy from GitHub
3. متغیرهای زیر رو تنظیم کن:
   - `BOT_TOKEN`
   - `OWNER_ID`
4. Deploy بزن ✅

## 📋 متغیرهای محیطی
| نام | توضیح |
|-----|-------|
| BOT_TOKEN | توکن ربات از BotFather |
| OWNER_ID | آیدی عددی مالک |

## 📞 پشتیبانی
برای سوالات، تیکت در خود ربات ارسال کنید.
